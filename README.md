# 银行贷款组合分析（Bank Loan Portfolio Analysis）

## 项目背景

本项目基于某金融机构的历史贷款数据，对贷款组合的整体质量、风险分布及关键影响因素进行分析，旨在为信贷业务提供数据支持。

通过 SQL 进行数据提取与指标计算，使用 Power BI 构建交互式看板，最终输出可落地的业务结论与建议。

## 分析目标

1. 评估整体贷款资产质量（好贷款 vs 坏贷款）
2. 分析不同维度下的坏账率差异（信用等级、贷款目的、期限、房屋所有权、地区等）
3. 识别高风险客群与业务场景
4. 为风控策略和业务优化提供数据依据

## 使用工具

- **SQL**（Navicat + MySQL）：数据提取、KPI计算、多维度分析
- **Power BI**：交互式数据可视化看板
- **Excel**：数据验证与辅助分析

## 数据说明

- 数据量：38,576 笔贷款记录
- 主要字段：贷款状态、信用等级、贷款目的、期限、房屋所有权、所在州、利率、DTI、贷款金额等

## 核心发现

### 1. 整体资产质量
- 总贷款笔数：38,576 笔
- 好贷款占比：**86.18%**
- 坏账率：**13.82%**
- 平均利率：12.05%
- 平均DTI：13.33%

### 2. 信用等级风险区分明显
| 信用等级 | 坏账率 |
|---------|--------|
| A       | 5.70%  |
| B       | 11.50% |
| C       | 16.02% |
| D       | 20.69% |
| E       | 24.80% |
| F       | 30.25% |
| G       | 31.31% |

信用等级从 A 到 G，坏账率显著上升，评级体系有效。

### 3. 高风险业务场景
- **小生意贷款（small business）** 坏账率最高，达到 **25.62%**
- **60个月长期贷款** 坏账率为 **22.34%**，约为36个月贷款的两倍
- 租房客户坏账率高于有按揭客户

### 4. 地区风险
- 佛罗里达（FL）、加州（CA）、佐治亚（GA）等州坏账率相对较高
- 加州虽然坏账率不是最高，但因业务体量最大，绝对坏账量最高

## 业务建议

1. 对 **小生意贷款** 提高准入门槛或加强贷后监控
2. 审慎发放 **60个月长期贷款**，可考虑提高定价或增加担保要求
3. 持续关注低信用等级（E/F/G）客户的风险敞口
4. 对高风险州的业务进行差异化风控策略
